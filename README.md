## 🚀 A couple things I'm building

### 🦷 DentalWave Assistant Scheduler

A scheduling tool I started building for the dental practice where I work.

What began as a web application has evolved into a more portable solution designed around the actual needs and limitations of the office.

`Java` `Spring Boot` `React` `PostgreSQL` `Vite`

This project has taught me a lot about software beyond just writing code. Requirements change, deployment gets complicated, users have real constraints, and sometimes the best solution looks very different from the first one you imagined.

### 🤖 LaunchBoardAI

A local desktop AI planning assistant I'm building to help organize school, projects, internship prep, and weekly goals.

`Python` `CustomTkinter` `Ollama`

One of my goals with this project is to explore what useful AI tools can look like when they run locally instead of depending entirely on cloud services.
